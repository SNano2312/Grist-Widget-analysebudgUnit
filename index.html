📂 Sources de données

        

          Budget_2025 / Budget_2026 : données budgétaires agrégées par CF/Programme/Fonds (Budget AE N, Conso AE N, CDa, RAR, OM, Payé CP…).

          Conso_2025 / Conso_2026 : opérations SAP ligne à ligne avec date comptable, montant, fournisseur, CC, type de valeur…

          Table Programmes (optionnel) : Col. A = N° programme • Col. B = Acronyme • Col. C = Date de fin.

          CDA par CC 2025 / CDA par CC 2026 (optionnel) : postes de commandes SAP par CC. Colonnes : Centre de coûts, Grpe de marchandises, Commande d'achat, Type de document, Fournisseur, Désignation, Valeur nette répartie, Valeur restante à livrer, Valeur restante à facturer, Élément d'OTP, Fonds, Date de livraison suivante.

          Ventilation CC 2025 / Ventilation CC 2026 (optionnel) : budget ventilé par CC. Colonnes : Programme de financement, Fonds, Budget AE N + une colonne par CC. Programmes sans OTP → Programme = NA.

          ⚠️ Noms de colonnes CC : doivent correspondre exactement aux CC des tables CDA et Conso. Un bandeau d'alerte signale toute discordance dans l'onglet Centres de coûts.
        

      


      

        
🔍 Barre de recherche

        

          Permanente en haut du widget. Recherche simultanée (min. 2 caractères) dans :

          • CDA par CC : N° commande (SIFAC+), fournisseur, code NACRES, désignation, CC

          • CONSO : N° commande, réf. OM Notilus (/#/OD ou /#/OMP), fournisseur

          • NACRES : N° commande, fournisseur, code NACRES

          Résultats avec badge coloré, année et montant. Touche Échap pour effacer.
        

      


      

        
📅 Filtre période personnalisable (Du / Au)

        

          Filtre les lignes de consommation CONSO par date comptable, en complément du filtre Année.

          • Tableau croisé : champs Du/Au dans la barre de filtres, propagés au drill-down

          • Drill-down Histogramme : barre Période (Du/Au + Filtrer + ✕) au-dessus du tableau de lignes

          ⚠️ Non applicable à Synthèse, Histogramme (barres), CC, NACRES — ces onglets lisent des agrégats budgétaires annuels.
        

      


      

        
💡 Subtilité AE / CP

        

          AE : enregistre les commandes d'achat. Une commande 2025 consomme du budget AE 2025, même si livraison et facture arrivent en 2026.

          CP : enregistre les décaissements. Un paiement 2026 peut liquider une commande 2025 — il apparaît dans Payé de l'exercice courant.

          • Payé (CP) > Budget AE N : normal — liquidation d'engagements antérieurs

          • CDa > Budget AE N : sur-engagement — alerte automatique

          • Non engagé = 0 : MAX(0, Budget − CDa)
        

      


      

        
🏠 Tableau de bord exécutif

        

          Affiché automatiquement au chargement. Contient :

          • 5 KPIs globaux : Budget total AE, Taux de consommation, Alertes actives, Cdes non soldées, Payé CP

          • Alertes, Top sous-consommés, Échéances proches ≤180j

          • 🔮 Indicateurs prédictifs (voir ci-dessous)

          • ⚠️ Indicateurs de risque (voir ci-dessous)

          • Accès rapide vers les onglets principaux
        

      


      

        
🔮 Indicateurs prédictifs

        

          Affichés dans le Tableau de bord et l'onglet Synthèse (dynamiques selon les filtres Année et CC). Calculés depuis les lignes CONSO "Commandes AE Original".


          📈 Projection fin d'année : rythme mensuel des 3 derniers mois extrapolé au 31/12 → taux de consommation projeté. ⚠️ Alerte si projection <80% avec >30j restants.


          ⏱ Délai 1ère commande : jours entre le 01/01 et la première commande SAP. Vert ≤30j, orange ≤90j, rouge >90j.


          🚀/🐌 Vélocité d'engagement : rythme du trimestre courant (3 derniers mois) vs trimestre précédent (3–6 mois). Accélération si >+10%, ralentissement si <-10%.
        

      


      

        
⚠️ Indicateurs de risque

        

          Affichés dans le Tableau de bord et l'onglet Synthèse, panneau séparé des indicateurs prédictifs. Contient 5 analyses :



          🎯 Score de risque par programme — note 0 à 10

          Synthèse pondérée : sous-consommation (0-3 pts), sur-engagement (0-2 pts), RAR élevé (0-2 pts), proximité échéance (0-2 pts), projection <80% (1 pt).

          Note ≥7 = rouge critique • ≥4 = orange • <4 = vert



          🏭 Concentration fournisseur

          Indice HHI (Herfindahl) calculé depuis CDA_CC : >0,25 = concentration élevée (rouge), >0,15 = modérée (orange), ≤0,15 = diversifié (vert).

          Top 3 fournisseurs avec barres et %. Section dépliable : matrice Programme × Fournisseur.



          📦 Engagements sans livraison

          Commandes CDA avec RAR livraison > 0 et date prévue dépassée depuis > X jours (seuil paramétrable, défaut 60j). Vue par fournisseur + détail cliquable (SIFAC+). Nécessite la colonne Date_de_livraison_suivante.



          ⏰ Budget restant engageable avant échéance

          Pour chaque programme avec budget non engagé, calcule le montant mensuel nécessaire pour consommer tout le budget avant l'échéance :

          €/mois = (Budget − CDa − RAR) ÷ Mois restants avant échéance

          Si pas de date de fin dans Table Programmes → utilise le 31/12 de l'année. Niveaux d'urgence :

          • 🔴 >50 000 €/mois • 🟠 >20 000 €/mois • 🟡 >5 000 €/mois • 🟢 ≤5 000 €/mois



          🔀 Effet de levier co-financement

          Détecte automatiquement les programmes financés par plusieurs fonds (données Budget). Pour chaque programme multi-fonds :

          • Barre empilée proportionnelle au budget de chaque fonds

          • Légende avec fonds, % du total, budget en €, et taux de consommation CDa par fonds

          • Coefficient de déséquilibre (écart-type des parts) : très déséquilibré / déséquilibré / équilibré

          Un déséquilibre important peut signaler un risque de sous-consommation sur le fonds le moins engagé.
        

      


      

        
📊 Synthèse & Histogramme

        

          Taux de consommation : Conso AE N ÷ Budget AE N — Vert ≥90% • Orange ≥50% • Rouge <50%

          Taux d'engagement : MIN((CDa+RAR+OM+NF) ÷ Budget, 100%)

          Drill-down : clic sur tuile ou barre → lignes CONSO avec N° Commande (SIFAC+) + filtre période Du/Au

          Comparaison 2025/2026 : barres groupées (Histogramme) ou courbes (Évolution)
        

      


      

        
🔀 Tableau croisé

        

          Vue tabulaire Budget AE, Conso AE, CDa, RAR, Payé, Reste à payer, Taux. Filtres : Année, Programme, Fonds, CC, Du/Au.

          Drill-down → détail CONSO filtré par période. Comparaison 2025/2026 avec évolution %.
        

      


      

        
🏦 Centres de coûts

        

          4 sous-onglets : Synthèse (cartes + tableau + alertes) • Évolution (courbes mensuelles) • Comparaison CC • NACRES par CC.

          Cartes : Budget, Non engagé, Reste à facturer, Prévision épuisement, Taux engagement, Taux paiement CP.

          Drill-down → commandes CDA + CONSO + boutons Voir NACRES et Voir Missions. Export CSV.
        

      


      

        
📅 Échéances

        

          Source : colonne C (Date de fin) de la Table Programmes.

          Timeline SVG : barre = taux conso AE, point = date de fin. Gris=expiré, Rouge=urgent faible conso, Orange=urgent, Vert=OK.

          Tableau : budget, conso, taux, J restants — clic → drill-down Histogramme.
        

      


      

        
🧪 NACRES & 🔴 Commandes non soldées

        

          NACRES : vues par code, fournisseur, détail. Sur marché (OSMA) / DC.01 agence voyage (violet) / Hors marché. Drill-down → commandes SIFAC+.

          Non soldées : CDA avec Reste à facturer > 0. N° Commande → SIFAC+.

          Délais livraison (sous-onglet) : CDA avec date prévue et RAR > 0. Statuts : Retard / Proche <30j / À venir. Vue fournisseur + drill-down.
        

      


      

        
💰 Paiements

        

          Top fournisseurs : classement par montant payé CP, comparaison 2025/2026.

          Délais paiement : délai facture → paiement. Rouge >60j, orange >30j.

          Répartition : donut par type de valeur + tableau par programme.

          ✈️ Missions : détection via Saisi par = NOTILUSBUS. Vues : par programme, par ordre de mission, évolution mensuelle.
          Lien Notilus /#/OD/ (OM) ou /#/OMP/ (ordre permanent via compte FG).
        

      


      

        
🗓️ Régularisation des ordres de mission — Indicateur décisionnel

        

          Sous-onglet de ✈️ Missions.



          Pourquoi c'est un indicateur décisionnel

          Une mission engagée dans SAP (dépense NOTILUSBUS) reste ouverte jusqu'à ce que l'agent rende son compte rendu et que le solde soit versé ou récupéré. Un ordre de mission non régularisé dans les délais :

          • immobilise du budget AE engagé qui ne peut pas être réalloué

          • génère un RAR artificiel qui fausse le taux de consommation réel

          • expose l'unité à un risque de contrôle comptable (clôture d'exercice)

          • peut indiquer une avance à l'agent non remboursée



          Comment ça fonctionne

          Le widget regroupe les dépenses NOTILUSBUS par bénéficiaire (nom de la personne, car le N° d'OM Notilus n'est pas exporté dans SAP). Un bénéficiaire est considéré clôturé s'il apparaît dans les paiements CP (CONSO_PMT) — c'est-à-dire si un paiement de solde a été effectué.



          Filtres : Année, Programme, Seuil de retard paramétrable (défaut 30j)



          KPIs : Bénéficiaires, Clôturés/Payés, À régulariser >X jours, Montant bloqué, Retard moyen



          Tableau : par bénéficiaire — montant engagé, date 1ère dépense, date dernière dépense, jours sans mouvement, statut :

          • ✓ Clôturé / Payé — paiement CP trouvé pour ce bénéficiaire

          • ⚠️ À régulariser — inactif depuis > seuil jours sans paiement

          • ↻ Actif — dépenses récentes, pas encore en retard



          ⚠️ Limite technique : la colonne Référence (N° OM Notilus) est vide dans les exports SAP — la liaison se fait par nom de bénéficiaire. Les N° de commandes SAP associés sont affichés comme référence alternative.
        

      


      

        
💶 Ratio Mission / Budget — Indicateur décisionnel

        

          Sous-onglet de ✈️ Missions.



          Pourquoi c'est un indicateur décisionnel

          Le budget d'une unité INRAE est destiné principalement aux achats de biens et services liés à la recherche. Les missions (déplacements) sont un poste nécessaire mais qui ne doit pas prendre une part disproportionnée. Un ratio élevé signale :

          • un programme très mobile dont le budget sera consommé en déplacements avant la fin de l'exercice, laissant peu de marge pour les achats

          • un déséquilibre à anticiper lors de la prochaine campagne budgétaire

          • un signal pour le responsable : faut-il arbitrer entre missions et achats ?



          Comment ça fonctionne

          Rapport entre le montant total des dépenses NOTILUSBUS et le budget AE du programme :

          Ratio = Σ Missions / Budget AE × 100

          Les montants missions utilisent Math.abs() pour neutraliser les corrections négatives SAP.



          Niveaux d'intensité :

          • 🔴 >15% — intensité élevée, vigilance requise

          • 🟠 >8% — intensité modérée

          • 🟢 ≤8% — intensité faible



          Vues disponibles :

          • KPIs globaux : total missions €, ratio global %, budget total

          • Tableau par programme : montant missions, budget, ratio %, intensité

          • Évolution mensuelle : graphique barres (violet = NOTILUSBUS) — permet de détecter les pics saisonniers (colloques, congrès) et d'anticiper les fins d'exercice
        

      


      

        
⚡ Liquidation AE→CP

        

          Disponible dans l'onglet ⚡ Liquidation AE→CP (groupe Achats) et dans le Tableau de bord.


          Méthode : croisement entre les commandes AE Original (CONSO) et les paiements CP (CONSO_PMT) via le N° de pièce de référence SAP. Pour chaque commande liquidée, calcule le nombre de jours entre la date de commande et la date du premier paiement CP associé.


          KPIs : délai moyen, délai médian, nombre de commandes liquidées, répartition ≤30j / 31-60j / 61-90j / >90j.


          Jauge de répartition : barre colorée montrant la proportion de commandes par tranche de délai (vert = rapide, rouge = lent).


          Vue par programme : délai moyen et médian par programme avec appréciation de fluidité (Rapide ≤30j / Normale ≤60j / Lente ≤90j / Très lente >90j).


          Détail cliquable : top 10 des commandes les plus longues à liquider, avec N° commande (SIFAC+), fournisseur, montant AE, date de commande, date du 1er paiement et délai.


          Note : seules les commandes effectivement payées apparaissent (CONSO_PMT avec montant > 0 et N° pièce de référence renseigné). Les commandes en cours de liquidation ne sont pas comptabilisées.
