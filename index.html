📂 Sources de données

        

          Budget_2025 / Budget_2026 : données budgétaires par CF/Programme/Fonds (Budget AE N, Conso AE N, CDa engagées N, RAR, OM, Payé CP…).

          Conso_2025 / Conso_2026 : opérations SAP ligne à ligne (type de valeur, montant, fournisseur, date, centre de coûts…).

          Table Programmes (optionnel) : Col. A = N° programme • Col. B = Acronyme • Col. C = Date de fin.

          Table NACRES 2025 / NACRES 2026 (optionnel) : postes de commande SAP par année. Col. A = Code NACRES • Col. E = Type document (OSMA=sur marché) • Col. I = Valeur nette répartie • Col. M = Reste à facturer • Col. S = Fonds.
        

      


      

        
🔢 Indicateurs budgétaires (Synthèse & Histogramme)

        

          Taux de consommation : Conso AE N ÷ Budget AE N × 100 — Vert ≥90% • Orange ≥50% • Rouge <50%

          Taux d'engagement : MIN((CDa+RAR+OM+NF) ÷ Budget AE N, 100%) — plafonné car le budget peut être révisé à la baisse après engagement. Note : le taux de conso peut être 100% alors que le taux d'engagement est <100% — ce sont deux comptabilités distinctes.

          Reste à engager : MAX(0, Budget AE N − CDa − RAR − OM − NF) — ce qu'il reste à commander. Peut être 0 même quand le taux de conso est 100%.

          Payé (CP) : colonne "Payé CP" du budget SAP. CP = Crédits de Paiement, comptabilité distincte des AE (Autorisations d'Engagement). Un montant payé supérieur au budget AE est normal : il correspond à des engagements d'années antérieures soldés sur l'exercice courant.

          Reste à payer : différence Conso AE − Payé CP. Peut être négatif pour la même raison (paiements d'engagements antérieurs).

          Prévision finale : si taux de conso ≥95% → Budget AE N (programme considéré bouclé) ; sinon MIN(Conso AE + CDa + RAR, Budget AE N).

          Alertes : 7 alertes automatiques détectées — sur-engagement, budget épuisé, RAR élevé (>20%), sous-consommation à J-90, échéance proche (<120j avec >5% non consommé), épuisement imminent (<30j au rythme actuel), inactivité (>90j).

          Drill-down : cliquer sur une tuile Synthèse bascule vers l'Histogramme filtré sur ce programme.
        

      


      

        
📈 Courbe d'évolution

        

          Commandes engagées : cumul mensuel des Commandes d'achat + Type montant Original, plafonné au budget.

          Fallback automatique sur Factures Original si aucune Commande d'achat pour ce fonds (ex : fonds consommé directement par factures).

          Prévision : MIN(dernier cumul + CDa + RAR, Budget). Si CDa+RAR≈0 : projection par rythme mensuel moyen des 3 derniers mois jusqu'à la date de fin du programme.

          Comparaison 2025/2026 : courbes superposées par mois calendaire. Fallback Factures par année si pas de CdA.
        

      


      

        
🔀 Tableau croisé

        

          Vue tabulaire de toutes les lignes budgétaires avec Budget AE, Conso AE, CDa, RAR, Payé, Reste à payer, Taux de conso.

          Drill-down : cliquer sur une ligne affiche le détail des opérations de consommation (CONSO) avec liens SIFAC+.

          Comparaison 2025/2026 : sélectionner "Comparaison 2025/2026" dans le filtre Année pour afficher Budget, Conso, Taux et Payé côte à côte avec évolution en %.
        

      


      

        
📊 Répartition — Montants nets SAP

        

          💳 Paiements : décaissements effectifs • 📄 Factures en cours : factures reçues non encore payées •
          🛒 Commandes en cours : solde résiduel des commandes ouvertes • 📝 Pièces préenregistrées : saisies en attente de validation.

          Les types "Réservation de fonds" et "Blocage de fonds" sont exclus (pas de dépenses réelles).
        

      


      

        
⏱ Délais de paiement

        

          Source : paiements effectifs (CONSO_PMT, montant > 0).

          Montant payé : total des paiements par fournisseur.

          Délai : Date MàJ Comptabilité budgétaire de la facture liée → Date MàJ du paiement, via le N° de pièce de référence partagé dans SAP.

          Vue par fournisseur : Nb paiements / Montant payé / Délai moyen / Délai max (rouge si >60j, orange si >30j).

          Vue détail : ligne par ligne triée par délai décroissant.
        

      


      

        
✈️ Missions (NOTILUSBUS)

        

          Détection des frais de mission via Saisi par = NOTILUSBUS dans les tables de conso.

          Engagé : Commandes d'achat + Type montant Original uniquement (exclut les réductions).

          Payé : depuis CONSO_PMT où Saisi par = NOTILUSBUS.

          Vue par programme : Engagé / Payé / Solde / Nb ordres de mission.

          Vue par ordre de mission : une ligne par référence NOTILUS-XXXX avec statut Soldé/En cours.

          Drill-down : cliquer sur une ligne affiche le détail des opérations avec N° CDA (lien SIFAC+) et N° OM (lien Notilus).

          N° OM : lien vers /#/OD/XXX (ordre de mission) ou /#/OMP/XXX si montant = 0,01€ (ordre permanent).
        

      


      

        
🧪 Onglet NACRES

        

          Sur marché : type document commence par OSMA • Hors marché : OSBC, CA, CAMA…

          Valeur nette répartie : montant total engagé • Reste à facturer : part non encore facturée.

          Commande non soldée : Reste > 0 — surlignée en orange dans la vue Détail. Filtre "Non soldées" disponible.

          KPI "Cdes non soldées" : nb / total sur le filtre actif.

          Données 2025 et 2026 fusionnées si les deux tables sont configurées. Filtre Année pour distinguer.
        

      


      

        
🔴 Commandes non soldées

        

          Liste toutes les lignes NACRES dont le Reste à facturer > 0, triées par reste décroissant.

          KPIs : Nb commandes non soldées / Reste total / dont marché / dont hors marché.

          Colonne Reste : en rouge avec le % non facturé (ex : 1 250 € (45%)).

          N° Commande cliquable vers SIFAC+. Filtres : Année / Programme / Fonds / Type. Export CSV disponible.
        

      


      

        
📋 Engagements pluriannuels

        

          Vue consolidée Budget + NACRES par Programme/Fonds.

          Budget : CDa engagées et RAR (Reste à réceptionner) pour 2025 et 2026 côte à côte.

          NACRES : commandes non soldées (Reste à facturer) rattachées au même Programme/Fonds.

          RAR Total : somme 2025+2026 — rouge si >10 000€, orange si >5 000€.

          N'affiche que les lignes ayant un RAR > 0 ou un reste NACRES > 0, triées par RAR décroissant.

⚙️ Configuration

        

          Tables obligatoires : Budget 2025, Budget 2026, Conso AE 2025, Conso AE 2026.

          Tables optionnelles : Table Programmes (dates de fin, acronymes), NACRES 2025, NACRES 2026.

          La configuration est mémorisée dans le navigateur (localStorage) et rechargée automatiquement.

          Filtre Centre de coûts : disponible dans tous les onglets — format XXXXAXXXX (ex : 0496C0001).

          Export CSV : disponible dans Tableau croisé, Top fournisseurs, Délais, Missions, NACRES, Commandes non soldées.
