📂 Sources de données

        

          Budget_2025 / Budget_2026 : données budgétaires par CF/Programme/Fonds (Budget AE N, Conso AE N, CDa engagées N, RAR, OM, Payé CP…).

          Conso_2025 / Conso_2026 : opérations SAP ligne à ligne (type de valeur, montant, fournisseur, date comptable, centre de coûts, compte budgétaire…).

          Table Programmes (optionnel) : Col. A = N° programme • Col. B = Acronyme • Col. C = Date de fin.

          CDA par CC 2025 / CDA par CC 2026 (optionnel) : postes de commandes SAP par CC. Colonnes clés : Centre de coûts, Grpe de marchandises, Commande d'achat, Type de document d'achat, Fournisseur, Désignation, Valeur nette répartie, Valeur restante à livrer, Valeur restante à facturer, Élément d'OTP, Fonds, Date de livraison suivante.

          Ventilation CC 2025 / Ventilation CC 2026 (optionnel) : budget ventilé par CC. Colonnes : Programme de financement, Fonds, Budget AE N, puis une colonne par CC (ex : 0496C0001, 0496C0002…). Les programmes sans OTP utilisent Programme = NA.

          ⚠️ Noms de colonnes CC : les noms de colonnes CC dans Ventilation_CC doivent correspondre exactement aux CC des tables CDA et Conso. Un bandeau d'alerte signale automatiquement toute discordance dans l'onglet Centres de coûts.
        

      


      

        
🔍 Barre de recherche & 📅 Filtre période

        

          Ces deux outils sont disponibles en permanence en haut du widget après le chargement de l'analyse.


          🔍 Recherche globale : champ texte de recherche (min. 2 caractères) qui cherche simultanément dans :

          • CDA par CC : N° commande SAP (lien SIFAC+), fournisseur, code NACRES, désignation, CC

          • CONSO : N° commande SAP, réf. OM Notilus (lien Notilus /#/OD ou /#/OMP), pièce de référence, fournisseur, CC/Programme

          • NACRES : N° commande, fournisseur, code NACRES

          Les résultats affichent un badge coloré (Commande / Mission / NACRES), l'année, le montant et un lien cliquable. Touche Échap pour effacer.


          📅 Filtre période personnalisable : champs Du / Au permettant de filtrer les opérations CONSO sur une plage de dates personnalisée (ex : du 01/09/2025 au 31/08/2026), en complément du filtre Année existant.

          Cliquer sur Appliquer pour activer le filtre. Le bouton ✕ Effacer période apparaît quand un filtre est actif.


          ⚠️ Onglets concernés par le filtre période : Évolution, Répartition, Top fournisseurs, Délais paiement, Missions, drill-downs.

          Onglets non concernés : Synthèse, Histogramme, Tableau croisé, Centres de coûts, NACRES, Cdes non soldées — car ces onglets lisent les agrégats budgétaires SAP (BUDGET) ou les postes de commandes (CDA_CC), qui sont des données annuelles sans date d'opération individuelle filtrables.
        

      


      

        
💡 Subtilité AE / CP — Pourquoi CDa ou Payé peuvent dépasser le Budget

        

          SAP gère deux comptabilités indépendantes :


          AE (Autorisations d'Engagement) : enregistre les engagements juridiques (commandes d'achat). Une commande passée en 2025 consomme du budget AE 2025, même si la livraison et la facture arrivent en 2026 ou 2027.


          CP (Crédits de Paiement) : enregistre les décaissements effectifs. Un paiement 2026 peut liquider une commande engagée en 2025 — il apparaît dans Payé de l'exercice courant, indépendamment de l'année d'engagement.


          Conséquences visibles dans le widget :

          • Payé (CP) > Budget AE N : normal — les paiements incluent la liquidation d'engagements d'années antérieures.

          • CDa > Budget AE N : sur-engagement — alerte déclenchée automatiquement.

          • Reste à payer négatif : normal — paiements supérieurs à la consommation AE de l'année.

          • Non engagé = 0 : budget entièrement engagé ou sur-engagé — MAX(0, Budget − CDa).
        

      


      

        
🏠 Tableau de bord exécutif

        

          Affiché automatiquement au chargement. Contient :

          • 5 KPIs globaux : Budget total AE, Taux de consommation (avec jauge), Alertes actives, Commandes non soldées, Payé CP

          • Alertes par programme : sur-engagement, RAR élevé, échéances proches sous-consommées — clic → Synthèse

          • Top sous-consommés : 3 programmes les plus en retard — clic → drill-down

          • Échéances proches ≤180j : triées par urgence — clic → Échéances

          • Accès rapide : boutons vers les onglets principaux
        

      


      

        
🏦 Onglet Centres de coûts

        

          4 sous-onglets : Synthèse (cartes + tableau + alertes) • Évolution (courbes mensuelles par CC) • Comparaison CC (Budget/CDa/Payé côte à côte) • NACRES par CC (répartition graphique + tableau).

          Chaque carte affiche : Budget alloué, Non engagé, Reste à facturer, Prévision d'épuisement (rythme 3 derniers mois), Taux d'engagement (CDa/Budget), Taux de paiement CP (Payé/Budget).

          Alertes automatiques : sur-engagement, RAR >20%, sous-engagement <10%.

          Drill-down sur ligne du tableau → commandes CDA + opérations SAP + boutons Voir NACRES et Voir Missions filtrés sur ce CC.

          Programmes NA : les dépenses sans OTP (ex : fonds SE sur 0496) doivent avoir une ligne NA / SE dans Ventilation CC. Export CSV disponible.
        

      


      

        
📅 Onglet Échéances

        

          Source : colonne C (Date de fin) de la Table Programmes. Seuls les programmes ayant une date de fin s'affichent.

          Vue Timeline SVG : axe temporel, barre de progression = taux de consommation AE, point = date de fin. Code couleur : gris = expiré, rouge = urgent (<90j faible conso), orange = urgent (<90j bonne conso), vert = OK.

          Vue Tableau : budget, conso, taux, jours restants — clic → drill-down Histogramme filtré.

          Filtres : Année, Statut (expiré/urgent/proche/OK). KPIs : compteurs par statut.
        

      


      

        
📊 Indicateurs budgétaires (Synthèse & Histogramme)

        

          Taux de consommation : Conso AE N ÷ Budget AE N — Vert ≥90% • Orange ≥50% • Rouge <50%

          Taux d'engagement : MIN((CDa+RAR+OM+NF) ÷ Budget AE N, 100%)

          Reste à engager : MAX(0, Budget AE N − CDa − RAR − OM − NF)

          Payé (CP) : peut dépasser le Budget AE (voir section AE/CP).

          Drill-down : clic sur tuile Synthèse ou barre Histogramme → opérations SAP détaillées avec N° Commande cliquable (SIFAC+).

          Comparaison 2025/2026 : barres groupées côte à côte (Histogramme) ou courbes superposées (Évolution).
        

      


      

        
🧪 NACRES / Postes de commande

        

          Source : CDA par CC 2025/2026. Vues : par code NACRES, par fournisseur, détail ligne par ligne.

          Sur marché : type OSMA • Agence voyage DC.01 : carte logée CAMA (violet) • Hors marché : OSBC, CA, CAMA hors DC.01.

          Drill-down : clic sur une ligne → toutes les commandes avec KPIs, N° commande (SIFAC+), CC, RAR et reste à facturer.
        

      


      

        
🔴 Commandes non soldées & 📦 Délais de livraison

        

          Non soldées : lignes CDA avec Reste à facturer > 0, triées par reste décroissant. N° Commande cliquable → SIFAC+.

          Délais livraison (sous-onglet) : lignes CDA avec date de livraison prévue (Date_de_livraison_suivante) et RAR > 0.

          • Statuts : En retard (date dépassée) • Proche (<30j) • À venir (>30j)

          • Vue agrégée par fournisseur (RAR total, nb retards, date prochaine livraison) — clic → drill-down détail commandes

          • Si la colonne Date_de_livraison_suivante est absente de la table CDA, un message explicatif s'affiche.
        

      


      

        
📋 Engagements pluriannuels & ✈️ Missions

        

          Engagements pluriannuels : consolidation Budget (CDa + RAR 2025+2026) + CDA non soldées par Programme/Fonds. N'affiche que les lignes avec RAR > 0 ou reste à facturer > 0.

          Missions : détection via Saisi par = NOTILUSBUS. Lien Notilus /#/OD/XXX (OM) ou /#/OMP/XXX (ordre permanent, détecté via compte budgétaire FG). Vues : par programme, par ordre de mission, évolution mensuelle.
