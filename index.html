📂 Sources de données

        

          Budget_2025 / Budget_2026 : données budgétaires par CF/Programme/Fonds (Budget AE N, Conso AE N, CDa engagées N, RAR, OM, Payé CP…).

          Conso_2025 / Conso_2026 : opérations SAP ligne à ligne (type de valeur, montant, fournisseur, date, centre de coûts, compte budgétaire…).

          Table Programmes (optionnel) : Col. A = N° programme • Col. B = Acronyme • Col. C = Date de fin.

          CDA par CC 2025 / CDA par CC 2026 (optionnel, remplace NACRES) : postes de commandes d'achat SAP par CC. Colonnes clés : Centre de coûts, Grpe de marchandises, Commande d'achat, Type de document d'achat, Fournisseur, Désignation, Valeur nette répartie, Valeur restante à livrer, Valeur restante à facturer, Élément d'OTP, Fonds.

          Ventilation_CC (optionnel) : ventilation du budget par Centre de coûts. Colonnes : Programme de financement, Fonds, Budget AE N, puis une colonne par CC (ex : 0496C0001, 0496C0002…).
        

      


      

        
🏦 Centres de coûts (CC) et ventilation budgétaire

        

          Le filtre Centre de coûts est disponible dans tous les onglets.

          Quand la table Ventilation_CC est configurée et qu'un CC est sélectionné :

          • Budget AE → montant alloué à ce CC dans Ventilation_CC

          • CDa engagées / RAR → depuis CDA par CC filtré sur ce CC

          • Conso AE → depuis Conso filtré sur ce CC (colonne Centre de coûts de SAP)

          • Payé / Reste à payer → 0 (les paiements SAP ne sont pas ventilés par CC dans l'export)

          Si aucun engagement n'existe encore sur un CC, toutes les valeurs sont 0 sauf le budget — c'est normal et se mettra à jour automatiquement dès que des commandes seront imputées sur ce CC dans SAP.
        

      


      

        
🔢 Indicateurs budgétaires (Synthèse & Histogramme)

        

          Taux de consommation : Conso AE N ÷ Budget AE N × 100 — Vert ≥90% • Orange ≥50% • Rouge <50%

          Taux d'engagement : MIN((CDa+RAR+OM+NF) ÷ Budget AE N, 100%) — plafonné car le budget peut être révisé à la baisse après engagement.

          Reste à engager : MAX(0, Budget AE N − CDa − RAR − OM − NF).

          Payé (CP) : Crédits de Paiement — comptabilité distincte des AE. Un montant payé supérieur au budget AE est normal (paiements d'engagements d'années antérieures).

          Prévision finale : si taux ≥95% → Budget AE N ; sinon MIN(Conso + CDa + RAR, Budget AE N).

          Alertes : 7 alertes automatiques — sur-engagement, budget épuisé, RAR élevé (>20%), sous-consommation critique J-90, échéance proche, épuisement imminent (<30j), inactivité >90j.

          Drill-down : cliquer sur une barre ou une tuile Synthèse affiche le détail des opérations CONSO avec liens SIFAC+.
        

      


      

        
📊 Histogramme

        

          Barres Budget / Conso / Non consommé par Programme, Fonds ou Année.

          Comparaison 2025/2026 : barres groupées Budget+Conso côte à côte pour les deux années.

          Drill-down : clic sur une barre → détail des lignes CONSO avec N° Commande (lien SIFAC+).
        

      


      

        
📈 Évolution mensuelle

        

          Commandes engagées : cumul mensuel des Commandes d'achat Original, plafonné au budget.

          Fallback automatique sur Factures Original si aucune commande pour ce fonds.

          Prévision : MIN(dernier cumul + CDa + RAR, Budget). Projection par rythme mensuel si pas d'engagements formels.

          Comparaison 2025/2026 : courbes superposées par mois calendaire.
        

      


      

        
🔀 Tableau croisé

        

          Vue tabulaire : Budget AE, Conso AE, CDa, RAR, Payé, Reste à payer, Taux de conso.

          Drill-down : clic sur une ligne → détail des opérations CONSO avec liens SIFAC+.

          Comparaison 2025/2026 : Budget, Conso, Taux, Payé côte à côte avec évolution %.
        

      


      

        
🧪 NACRES / Postes de commande

        

          Source : tables CDA par CC 2025/2026 si configurées, sinon tables NACRES 2025/2026.

          Sur marché : type document OSMA • Agence voyage (DC.01) : carte logée CAMA sur NACRES DC.01, affiché en violet • Hors marché : OSBC, CA, CAMA (hors DC.01).

          Valeur nette répartie : montant total engagé • Reste à facturer : part non encore facturée.

          Avec le filtre Centre de coûts, seules les lignes de ce CC sont affichées (filtrage direct sur la colonne CC de la table CDA).
        

      


      

        
🔴 Commandes non soldées

        

          Lignes CDA avec Reste à facturer > 0, triées par reste décroissant.

          N° Commande cliquable vers SIFAC+. Filtres : Année / Programme / Fonds / CC / Type.
        

      


      

        
📊 Répartition

        

          💳 Paiements : décaissements effectifs • 📄 Factures en cours : factures reçues non payées •
          🛒 Commandes en cours : solde résiduel des commandes • 📝 Pièces préenregistrées : saisies en attente.

          Les Réservations et Blocages de fonds sont exclus (pas de dépenses réelles).
        

      


      

        
⏱ Délais de paiement

        

          Délai calculé entre la date de la facture et la date du paiement via le N° de pièce de référence SAP.

          Vue par fournisseur (délai moyen/max) ou détail ligne par ligne. Rouge >60j, orange >30j.
        

      


      

        
✈️ Missions (NOTILUSBUS)

        

          Détection via Saisi par = NOTILUSBUS.

          OMP (Ordre de Mission Permanent) : détecté via Compte budgétaire = FG → lien Notilus /#/OMP/XXX.

          OM (Ordre de Mission) : Compte budgétaire = FF → lien Notilus /#/OD/XXX.

          Vue par programme, par ordre de mission, ou évolution mensuelle.
        

      


      

        
📋 Engagements pluriannuels

        

          Consolidation Budget (CDa + RAR 2025 + 2026) + NACRES/CDA non soldées par Programme/Fonds.

          N'affiche que les lignes ayant un RAR > 0 ou un reste à facturer > 0.
